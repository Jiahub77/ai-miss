## 素材处理与还原边界

对多个滚动位置进行了对齐与拼接，重建照片可见区域，避免引入手机状态栏、悬浮辅助按钮、评论和点赞栏。大多数照片以这组重建素材制作。录屏首图顶部被系统界面遮挡，因此首屏采用同一录屏中的干净站姿合照，不生成或猜测被遮挡的人脸。

书法「囍」提取自新录屏；手写英文字样为透明图形资源。正文、日期、日历、倒计时与地点均以原生 HTML 渲染，不是整页截图播放器。照片清晰度仍受录屏分辨率限制；不能声称与原素材逐像素一致。

## 浏览与动效

- 默认停留约 3.2 秒后开始慢速向下浏览，速度约 82 CSS px/秒，接近录屏节奏。
- 右上角「Ⅱ / ▷」暂停或恢复自动滚动。
- 手指触碰页面、鼠标滚轮或方向键会停止自动滚动，交给用户浏览。
- 滚到结尾后停留约 2.8 秒，再回到开头。
- 音乐仅在点击音符后播放；切入后台暂停音乐，自动滚动也暂停推进。
- 图片和寄语随滚动轻微浮现，双照片与结尾叠加轻量花瓣。
- 减少动态效果开启时禁用自动滚动、浮现与花瓣；始终可手动浏览。

## 文件与配置

- index.html：页面内容。
- styles.css：白底长页与响应式布局。
- app.js：日历、倒计时、自动滚动、暂停、音乐与花瓣。
- config.js：姓名、日期、地点、时间、导航和滚动参数。
- assets/ref2-*：新录屏照片、书法、英文标题与音乐。

填写 config.js 的 address 后可启用地图搜索；若填写准确的 HTTPS navigationUrl，将优先使用该链接。
